## Описание диагностики

Код (комментарии и идентификаторы — имена переменных, процедур, функций, параметров и т.п.) должен быть написан на русском или английском языке. Использование украинских букв не допускается.

Так как украинский и русский языки используют общий кириллический алфавит, надёжно отличить украинский текст можно только по буквам, которых нет в русском алфавите: `і`, `ї`, `є`, `ґ` (и их заглавные варианты `І`, `Ї`, `Є`, `Ґ`). Поэтому диагностика срабатывает только при наличии этих букв. Набор букв задаётся параметром `letters` в виде регулярного выражения.

Строковые литералы не проверяются: они часто содержат текст интерфейса, в том числе на украинском языке.

## Примеры

Срабатывает (буква `і` в комментарии, буква `є`/`і` в идентификаторе):

```bsl
// Перевірка вхідних даних
Перем Єдність;
```

Не срабатывает (русский и английский):

```bsl
// Проверка входных данных
Перем Единство;
Сообщить("Привіт, світ"); // текст в строке не проверяется
```
